This website

A place for my work, process and more informal reflections.

Alexander Söderholm · 1 Nov 2026

The thought of creating a website is something that has been lingering in the back of my head since my third year of architecture school. I remember thinking about it as a place to store my work, which would enable sending a smaller portfolio with a link to read more on the web. Since then, my idea of what a website can be has surely developed along with my skills (and AI tools) in creating one.

Today, as I finally get to launch this thing, I see it as an archive for the work that no longer fits inside the portfolio, and a place where I can leave things like this: smaller reflections that still tell something about me, but would not fit in the project section.

To create this website, I started by taking a five-day course with Code Institute to get the very basic hang of HTML and CSS. After that, I have been diving into endless YouTube videos on CSS functions, user experience, typography… yes, you name it. The whole website has been written in Visual Studio Code (VSC) and I have been able to do it entirely for free.

But I have also had help, of course. Without Gemini and VSC's integrated Copilot this website probably would not have seen the light of day as it looks right now. It has been a constant process of learning, prompting, debugging and then retuning the code to become part of what I want the user experience to become, rather than what the AI thinks it should be.

I am far from finished, as you might notice, but I am glad to have you here for the journey!
